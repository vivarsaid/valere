# Fotos de frascos

Pon aquí la foto de cada frasco en formato **.webp**, con fondo transparente si se puede.

El nombre del archivo es el valor de `"foto"` en `data/perfumes.json` → `"modelos"`:

```json
"modelos": { "eros": { "foto": "eros", ... } }   →   images/frascos/eros.webp
```

Si un perfume no tiene foto, se muestra el frasco dibujado con su color.
